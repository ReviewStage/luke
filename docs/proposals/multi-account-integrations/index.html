Multiple accounts per integration

Design show for docs/proposals/multi-account-integrations.md: Settings › Integrations, the coding agent's MCP popover, a mention, and what the agent is handed, with one developer holding two Notion workspaces, Acme and Personal. Every label is the provider's name and the account's name. A developer with one account per provider sees exactly today's rows; the only addition is Add another account in each row's actions menu.

2 · Settings, grouped under one provider row alternative (B)

The same data with the provider as a parent row and its accounts beneath it. It reads well with three or more accounts, but it gives the one-account majority a second shape to learn and a nested row for every popover and search hit. The proposal recommends A and keeps B for a provider whose accounts outgrow a flat list.

3 · The coding agent's MCP popover

One row and one switch per account. Switching off Notion · Personal writes its connection name (notion-2) to the agent's disabled_servers and leaves Notion · Acme on. A search for a tool shows each account's hit on its own row. A new account starts on for every agent, as a newly connected provider does today.

4 · A mention, and what the agent is handed

The mention picker lists each account. The chip says which one, and its address names the connection (luke://mcp/notion-2, or luke://mcp/notion-2/notion-search for a tool). An old address (luke://mcp/notion) still means the first account. The agent gets one eve connection per account. Connection names may hold only lowercase letters, digits, and dashes, so the first account keeps notion and each added one is notion-2, notion-3, and so on. Each description names the account.

5 · Disconnecting one account

Disconnect deletes that account's row first, then revokes that one subject's grant at Connect. The other Notion row and its grant are untouched. A coding agent that had the removed account switched off keeps a stale notion-2 entry in disabled_servers, which is harmless: it names no connection. An account added later under the same name inherits that switch, just as reconnecting a provider does today.

Disconnect Notion · Personal?
