# `@sidecar/surface`

`repository-checks.sh` fails on drift in the generated files under
`src/generated/`, so regenerate from the design sources rather than hand-editing.

This package stays React-free. `@sidecar/panel` is the shared React layer that
traces the generated artwork into both the desktop panel and the marketing mock,
so provider geometry, row anatomy, face, glyphs, and base panel CSS have one
implementation.

The urgency *value set* is `@sidecar/session`'s — a fixture snapshot and a session
model both name it, and neither may reach presentation for a value set. What this
package owns is only the wording and the ranking, so the marketing mock cannot
advertise a different sentence or a different top row than the product draws.
