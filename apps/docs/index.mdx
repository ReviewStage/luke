Vespin is an inbox for all your coding agents.

You describe a task, and Claude Code or Codex agents work on it in cloud sandboxes and open pull requests. When an agent needs a decision, a to-do, or your review, it posts a thread to your Inbox, and you answer it there.

<Frame>
  <img src="/images/inbox.png" alt="The Vespin Inbox: threads from coding agents, one open with an agent asking you to approve its direction" />
</Frame>

Each task has:

- A plan: one Markdown document that you, your teammates, and its agents edit.
- One or more agents, each with its own transcript.
- The pull requests its agents open, which you review in Vespin.
- Threads in your Inbox for what its agents need from you.

Agents run on your own Claude or ChatGPT plan, or on an API key. Vespin itself is free and [open source](https://github.com/ReviewStage/vespin).

## Get started

- [Install](/install): get the Mac app or open the web app.
- [Your first task](/quickstart): start a task, answer its agent, and merge its pull request.
- [Connect GitHub](/connect-github): give agents your repositories.
- [Models and who pays](/models): connect Claude or Codex on a plan or an API key.
