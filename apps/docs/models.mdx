---
title: "Models and who pays"
description: "Connect Claude or Codex on a plan or an API key"
---

Vespin doesn't bill for model usage. Each agent runs on a plan or an API key you connect in **Settings › Agents**, and its usage counts against that plan's limits or is billed to that key.

| Agent | Plan | API key |
| --- | --- | --- |
| Claude | Claude plan | Anthropic API key |
| Codex | ChatGPT plan | OpenAI API key |

## Connect a Claude plan

1. In a terminal, run `claude setup-token`.
2. In **Settings › Agents**, click **Connect Claude** and paste the token it printed.

## Connect a ChatGPT plan

In **Settings › Agents**, click **Connect Codex**, then **Continue with ChatGPT**, and finish signing in in your browser. This works only in the Mac app.

## Use an API key

Click **Connect Claude** or **Connect Codex**, choose **API key**, and paste a key from Anthropic or OpenAI. **Get key** opens the provider's page for making one.

## Set the default model

**Default model**, **Effort**, and **Context** in **Settings › Agents** apply to new agents. To change one agent's model, use the model menu in its message box. The menu's last line names the plan or key that pays for that agent.
