---
title: "Connect GitHub"
description: "Give agents your repositories"
---

A workspace connects to GitHub once. Every agent in the workspace reaches the repositories that connection allows, and opens pull requests as you.

## Choose how to connect

Open **Settings › Workspace › Workspace connections** and choose one:

- **GitHub App** (recommended): install Vespin's GitHub App and choose which repositories it can reach. GitHub tells Vespin about reviews, comments, and failed checks as they happen, so agents answer them right away.
- **Personal access token**: paste a classic token with the `repo` scope. Vespin checks your open pull requests for reviews, comments, and checks about once a minute.

## Give agents GitHub's tools

The workspace connection lets agents check out repositories and push to them. To also let agents use GitHub's own tools as you, such as reading issues or searching code, connect GitHub in **Settings › Integrations**.
