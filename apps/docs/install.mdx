Vespin is a Mac app for Apple silicon on macOS 14 or newer, and a web app at [vespin.dev/app](https://vespin.dev/app). Both open the same workspace.

## Download for Mac

1. Download the DMG from the [latest release](https://github.com/ReviewStage/vespin/releases/latest).
2. Drag Vespin to your Applications folder.
3. Open Vespin and sign in with Google or GitHub.

## Setup

A new account walks through setup. You need an agent and GitHub to start a task.

### Connect an agent

Agents run on your own plan or API key. Vespin doesn't bill for model usage.

- **Claude plan**: run `claude setup-token` in a terminal and paste what it prints.
- **ChatGPT plan**: click **Continue with ChatGPT**. This works only in the Mac app.
- **API key**: paste an Anthropic or OpenAI key.

With both a plan and a key saved, **New Claude agents use** and **New Codex agents use** in **Settings › Agents** choose which one pays for new agents.

### Connect GitHub

- **GitHub App** (recommended): choose which repositories it can reach. Agents hear about reviews, comments, and failed checks as they happen.
- **Personal access token**: a classic token with the `repo` scope. Vespin checks your pull requests about once a minute, and the token can reach every repository your GitHub account can.

You can skip GitHub during setup and connect it later in **Settings › Workspace**.
